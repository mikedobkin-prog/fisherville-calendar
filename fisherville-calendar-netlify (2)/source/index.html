Add Google Calendar

You can add several calendars to the main view. Choose Main calendar for each one. Lunch Menu and Upcoming events use their own sources.

Find the ID in Google Calendar, Settings, select your calendar, then Integrate calendar. Public calendars display directly on this board. Private calendars need a separate sign in integration.

The live page reads public Google Calendars automatically and refreshes every minute. No API key is needed here.

API key for downloaded HTML (optional)

One key connects all public calendars. Enable the Google Calendar API in your Google Cloud project, then create an API key in Credentials. Restrict it to the Calendar API and this website address. Your key stays in this browser. It is only needed when using the downloaded HTML file.

For public display, share only the calendars you intend others to see. Google sharing instructions
